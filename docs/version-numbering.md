# 製品版の番号

OperationRecorderの製品版は`0.1.6`を使用する。メジャー0を付け忘れていたため、2026-11-03に利用者が指定した次の対応で、ソースの全履歴とタグ・公開配布物の番号を訂正した。

| 訂正前 | 訂正後 |
|---|---|
| 1.3.2 | 0.1.2 |
| 1.4.0 | 0.1.3 |
| 1.4.1 | 0.1.4 |
| 1.5.0 | 0.1.5 |
| 1.6.0 | 0.1.6 |

過去のGitコミットIDとタグ参照先は変わっている。既存のcloneから古い履歴を混ぜてpushせず、新しい履歴を取得して作業する。

過去の版別報告の版表記も訂正しているが、当時の実行で得たEXEの採用SHA、容量、ハッシュ、バックアップ名等の証跡は当時の値である。番号訂正後に作り直す配布物の値は、今回の[番号訂正報告](../dev/history/v0.1.6/v0.1.6-renumber.md)を参照する。

旧番号を表示する導入済みアプリの自動ダウングレードは行わない。旧1.x系を導入しているPCでは、番号訂正後のsetupを明示して再導入する必要がある。今回の番号訂正だけで現PCのアプリや利用者設定を変更しない。

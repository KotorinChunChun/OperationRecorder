# 製品版の番号

現在の開発版は`0.1.15`。読み取り専用の構成診断でUI構造と再観測の失敗理由を区別する。無効な背後窓がある場合の候補取得は`0.1.14`、別ウィンドウへの工程引継ぎと読み取り専用の設定候補取得は`0.1.13`、パスワード欄のマスクは`0.1.12`、固定領域照合は`0.1.11`で追加した。

外部証拠APIは`0.1.7`で追加し、`0.1.8`で録画エンジンを整理した。並行した外部証拠の開発では`0.1.9`でWGCとウィンドウ群、`0.1.10`で単発取得を追加した。GitHubで配布した`0.1.9`はKotorinToysの配布台帳との互換性を修正し、配布版`0.1.10`は導入済みの`0.1.8`・`0.1.9`からの上書き更新に対応した。各版の開発・配布記録は[開発資料の目録](../dev/README.md)を参照。

以下は番号訂正時の製品版`0.1.6`の記録。メジャー0を付け忘れていたため、2026-11-03に利用者が指定した次の対応で、ソースの全履歴とタグ・公開配布物の番号を訂正した。

| 訂正前 | 訂正後 |
|---|---|
| 1.3.2 | 0.1.2 |
| 1.4.0 | 0.1.3 |
| 1.4.1 | 0.1.4 |
| 1.5.0 | 0.1.5 |
| 1.6.0 | 0.1.6 |

過去のGitコミットIDとタグ参照先は変わっている。既存のcloneから古い履歴を混ぜてpushせず、新しい履歴を取得して作業する。

過去の版別報告の版表記も訂正しているが、当時の実行で得たEXEの採用SHA、容量、ハッシュ、バックアップ名等の証跡は当時の値である。番号訂正後に作り直す配布物の値は、今回の[番号訂正報告](https://github.com/KotorinChunChun/OperationRecorder/blob/main/dev/history/v0.1.6/v0.1.6-renumber.md)を参照する。

旧番号を表示する導入済みアプリの自動ダウングレードは行わない。旧1.x系を導入しているPCでは、番号訂正後のsetupを明示して再導入する必要がある。今回の番号訂正だけで現PCのアプリや利用者設定を変更しない。

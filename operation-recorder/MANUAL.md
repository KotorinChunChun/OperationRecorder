# OperationRecorder マニュアル

PC で行う操作(クリック・キー操作・文字の入力)を自動で記録し、操作前・操作後のスクリーンショット付きの
操作手順書(Markdown 形式の md ファイル)を作るツールです。

- 手順書を作るために、いちいちスクリーンショットを撮って貼り付ける必要はありません。いつもどおり操作するだけで、
  「『保存』ボタンをクリックします」のような文章と画像が 1 手順ずつ記録されます。
- 記録には、画面の要素の名前やウィンドウ内の位置も保存されます。AI が操作を再現するための手順書(AI 向け)も作れます。

---

## 1. 使い始める

### 1.1 インストール

KotorinToysの一覧からOperationRecorderを選び、公開カタログを更新して「インストール」を押します。
インストール完了後、「起動」と「画面を表示」から利用できます。.NETランタイムは同梱しているため、別途導入する必要はありません。
単体で導入する場合は[GitHub Releases](https://github.com/KotorinChunChun/OperationRecorder/releases)から対象版の`OperationRecorder-<版>-setup.exe`を実行します。管理者権限は不要です。
正式インストーラーはスタートメニューへOperationRecorderを登録し、アプリは追加登録を提案しません。

従来の単体zipを使用する場合の手順は次のとおりです。

1. 配布された zip ファイルを、好きなフォルダ(例: `C:\Tools\操作記録ツール`)に展開します。
2. `OperationRecorder.exe` をダブルクリックします。
3. 初めて起動したときに「スタートメニューに登録しますか?」と聞かれるので、「はい」を選びます。
   スタートメニューに次の 2 つが登録されます(このユーザーだけ。管理者権限は要りません)。
   - **操作記録ツール** … ツールの画面を開く
   - **操作記録ツール(すぐに記録)** … 前回の設定ですぐ記録を始める

> exe を別のフォルダへ移したときは、起動時に「登録し直しますか?」と聞かれます。「はい」を選んでください。

### 1.2 Windows の起動時に起動する

自動起動は新規OFFです。KotorinToysの「本体設定・自動起動」で管理し、単体アプリから新しいスタートアップ登録は作りません。
正式インストーラーで導入した後、本体から有効にできます。開発EXEや単体zipの展開先は正式導入として扱いません。
旧版のスタートアップ登録がある場合は「設定」タブに案内し、その登録を自動で上書き・削除しません。
`--startup` を使うと画面を出さずに常駐します。常駐中も開始キー（既定Ctrl+Shift+F9）で記録を始められます。

起動のしかたは、次の引数でも変えられます。

| 起動のしかた | 起動していないとき | すでに起動しているとき |
|---|---|---|
| `OperationRecorder.exe --settings`(引数なしも同じ) | 起動して設定の画面を出す | 起動中のツールの設定の画面を出す |
| `OperationRecorder.exe --startup` | 画面を出さず、タスクトレイに常駐して起動する(スタートアップからの起動で使う) | 何もしない |
| `OperationRecorder.exe --record` | 前回の設定ですぐ記録を始める | 起動中のツールで記録を始める |

`--startup` は `-startup` `/startup` `startup` と書いても同じです(ほかの引数も同じ)。
### 1.3 アンインストール

正式インストーラーで導入した場合は、KotorinToysの「アンインストール」またはWindowsの「インストールされているアプリ」から削除します。
記録中・保存中・未保存編集がある場合は、先に記録や編集を保存してください。設定と記録は保持されます。

単体zipで使用している場合は次の手順です。

1. ツールの「設定」タブでスタートメニューの「登録を解除」を押します。旧版のスタートアップ登録がある場合は、その案内に従って登録元を確認します。
2. トレイのアイコンを右クリックして「操作記録ツールを終了」を選びます。
3. 展開したフォルダを削除します。設定は `%APPDATA%\OperationRecorder` に残るので、不要なら削除してください。
   記録(`ドキュメント\OperationRecords`)は消えません。

### 1.4 画面の構成

タブの上の帯には、どのタブを開いていても使えるように **「記録を開始」ボタン** と **記録の名前** が並んでいます。

| タブ | できること |
|---|---|
| 記録対象 | 何をどう記録するか: 撮影モード・記録する対象・記録中の画面表示(赤い枠・撮影の合図・オーバーレイ)・記録を保存するフォルダ |
| 撮影の設定 | いつ撮るか: 操作の種類ごとに「記録するか」「操作前・操作後を撮るか」、撮るタイミング(ms)、撮った画像に描くクリック位置の丸 |
| 出力の設定 | 報告書をどう作るか: 冒頭に載せる解説・保存したときに出力する報告書(文章の種類・ファイルの形式と、作ったら開くか(既定は HTML を開く))・画像に描く印・md / HTML を保存するフォルダ |
| ショートカットキー | 記録の開始・1 手取消・取り直し・保存して終了のキーを変える(2.4) |
| 記録一覧・編集・出力 | 過去の記録を見る。手順と画像(操作前・操作後を横並び)の確認、手順の文章や名前・解説の修正・手順の削除、HTML / Markdown の出力、テンプレートの編集、記録の削除 |
| 使い方 | このマニュアルを表示する |
| 設定 | スタートメニューへの登録、テンプレートの場所、管理者として再起動 |

ウィンドウの × を押しても、ツールはタスクトレイ(画面右下)に残ります。トレイにある間も
**Ctrl+Shift+F9**(記録の開始のキー。2.4 で変えられます。以下、キーは既定のもので書きます)でいつでも記録を始められます。完全に終了するときは、トレイのアイコンを右クリックして
「操作記録ツールを終了」を選びます。

トレイのアイコンの丸の色で、状態が分かります。

| 丸の色 | 状態 |
|---|---|
| 灰色 | 待機中(Ctrl+Shift+F9 でいつでも記録を始められる) |
| 赤色 | 記録中 |

## 2. 記録する

### 2.1 基本の流れ

1. 次の項目を決めます(前回の内容が残っているので、変えるものだけで構いません)。
   - **記録の名前**(タブの上の帯) … 例「受注登録」。報告書の見出しが「受注登録操作手順書」になり、記録フォルダ名の末尾にも付きます。
   - **解説**(「出力の設定」タブ) … 報告書の冒頭「本書では〇〇の操作手順について説明する」の後に載せる説明文。
   - **撮影モードと対象**(「記録対象」タブ。次の表)
   - **出力する報告書**(「出力の設定」タブ) … ① 文章の種類(テンプレート) ② ファイルの形式(md / HTML)。3 章を参照
2. タブの上の「記録を開始」を押すと、ツールの画面がトレイに隠れて記録が始まります。
   または、記録したいアプリに切り替えて **Ctrl+Shift+F9** を押します。待機中(トレイにあるとき)はいつでも受け付けます。
   (オーバーレイは記録中だけ出ます)
3. いつもどおり操作します。クリックや Enter などのたびに、自動で画面が撮られます。
4. 終わったら **Ctrl+Shift+F12** を押します。記録が保存され、md / HTML が出力されます。
   「② ファイルの形式」の表で、HTML・md を「作る」か、作ったら「開く」かを決めます(既定は HTML を作って開く。作らない形式は開けません)。「保存したら記録フォルダを開く」もあります。

スタートメニューの「操作記録ツール(すぐに記録)」を使うと、前回の設定のまま 3 から始められます。

### 2.2 撮影モード

| モード | 撮る範囲 | 向いている使い方 |
|---|---|---|
| Window | 選んだ 1 つのウィンドウ | 1 画面で完結する操作。ダイアログ上の操作は記録されない |
| App | 選んだアプリのウィンドウ全部 | ダイアログやメニューも含めて、1 つのアプリの操作を記録する(ふつうはこれ) |
| Active | 操作したウィンドウをその都度 | 複数のアプリをまたぐ操作 |
| Desktop | 1 つのディスプレイ全体(対象のウィンドウがあるディスプレイ・番号で選んだディスプレイ) | 1 画面の様子を丸ごと残したいとき |
| AllDesktops | PC のすべてのディスプレイを合わせた全体 | 複数のディスプレイをまたぐ操作を丸ごと残したいとき |

- Window / App では、対象の外にある画面(重なった他のアプリなど)は**斜線で塗りつぶされ**、画像に残りません。
- **Active / Desktop / AllDesktops では、関係ない画面(メール・チャットなど)もそのまま写り、そこで入力した文字も記録されます。**
  記録を始める前に、写ってほしくない画面を閉じてください。
- AllDesktops は画像が大きいので、撮影の間隔を自動で広げます(操作前の画面が、指定した ms より少し前のものになることがあります)。
  ディスプレイの大きさや位置が揃っていないときの、ディスプレイの無い隙間は塗りつぶします。
- Window / App / Desktop の対象は、次のどれかで決めます(Desktop は「記録する対象」の一覧で選びます)。

| 決め方 | 対象 |
|---|---|
| 記録を始めてから、最初にクリックしたもの | 最初にクリックしたウィンドウ(Desktop はそれが映っているディスプレイ)。最初のクリックは記録されません |
| 記録開始のキーを押したときに、前面にあるもの | Ctrl+Shift+F9 を押した時点で前面にあるウィンドウ(App はそのアプリ、Desktop はそのウィンドウがいちばん広く映っているディスプレイ)。キーを押した時点で決めるので「ボタンを押したらすぐ始める」は選べません。前面に記録できるウィンドウが無いとき(デスクトップを選んでいたときなど)は、最初にクリックしたものになります |
| 一覧から選ぶ | 一覧で選んだウィンドウ(Desktop は番号で選んだディスプレイ) |

### 2.3 記録中の画面表示

記録中は、次の表示が出ます。**どれも記録の画像には写らず**、表示の上でのクリックも記録されません
(Windows 10 バージョン 2004 以降)。「記録対象」タブで、それぞれ出さないようにもできます。

| 表示 | 内容 |
|---|---|
| 赤い枠 | 記録の対象になっているウィンドウ(Desktop ではディスプレイ)を囲います。クリックは枠を素通りして下のウィンドウに届きます |
| 撮影の合図 | 撮影した瞬間に枠が黄色く光り、クリックした位置に丸が広がって消えます(左クリック = 赤、右 = 青、中 = 緑、ホイール = 橙) |
| オーバーレイ | いちばん上に記録の対象(ウィンドウ・アプリ・ディスプレイの名前。「最初にクリックしたもの」はクリックした時点で名前に変わる)、「記録中 N 手」、操作ボタン(1 手取消・取り直し・保存して終了)、使えるキーの一覧、直近 10 手のサムネイルと手順の文。ドラッグで好きな場所に動かせます。「記録対象」タブで、マウスがあるウィンドウに重なったときに重ならない画面の隅へ自動で移動させることもできます(既定はオン) |

### 2.4 記録中に使うキー

どのアプリを操作中でも効きます。これらのキー自体は記録されません。

| キー | 動作 |
|---|---|
| Ctrl+Shift(この 2 つだけを押して離す) | 今の画面をキャプチャして、1 つの手順にする(見出しは「手順 N.」だけ) |
| Win+Shift+S | Windows の切り取りが始まる前の、押した瞬間の画面をキャプチャして、1 つの手順にする |
| Ctrl+Shift+F9 | 記録を始める |
| Ctrl+Shift+F10 | 直前の 1 手を取り消す(続けて押すと、さらに前へ戻る) |
| Ctrl+Shift+F11 | 今の記録を捨てて、同じ設定で最初から記録し直す(Ctrl+Shift+F9 で始める) |
| Ctrl+Shift+F12 | 記録を保存して終了し、md / HTML を出力する |

F9〜F12 の 4 つは「ショートカットキー」タブで変えられます。操作ごとに Ctrl・Shift・Alt・Win のチェックと、キー(F1〜F24・A〜Z・0〜9 など)を
選ぶと、すぐに保存して使えるようになります(記録中に変えたときは、次の記録から)。次の組み合わせは使えないので、理由が赤く表示され、前の設定のままになります。

- キーを選んでいない / Ctrl・Alt・Win のどれも付いていない(Shift だけや修飾キーなしでは、ふだんの入力と区別できない)
- 2 つの操作に同じ組み合わせを使っている
- Alt+F4・Ctrl+S・Ctrl+C・Win+L など、Windows やアプリでよく使う組み合わせ

画面・トレイのメニュー・通知に出るキーの表示も、変えたキーに合わせて変わります。
コマンド(PowerShell)で記録するときのキーは、既定の Ctrl+Shift+F9〜F12 のままです。

オーバーレイのボタンや、トレイのアイコンを右クリックしたメニューからも、同じ操作ができます。
取り消し・キャプチャのときは音が鳴ります。

### 2.5 何が記録されるか

| 操作 | 記録のされ方 |
|---|---|
| クリック・ダブルクリック・右クリック・ドラッグ | 押す直前(既定 0.2 秒前)と、離した後(既定 0.5 秒後)の画面 |
| マウスホイール | **既定では記録しません**(「撮影の設定」タブでオンにできます)。オンにすると、回す直前と回し終えた後の画面を記録します。同じウィンドウで続けて回した分は 1 つの手順にまとめ、下に回してから上に戻した分は差し引きます(差し引き 0 なら記録しません) |
| キー(A〜Z・1〜0・F1〜F24・十字キー・Enter や Tab などの特殊キー・Ctrl / Alt / Win との組み合わせ) | 押す直前と、押した後の画面。**既定ではどのキーも記録しない**(下の表のグループごとに「記録する」にできる) |
| テキストボックスへの入力 | 入力欄にカーソルが入った時点と、外れた時点の画面。「『氏名』欄に『山田』と入力します」という手順になる |
| Ctrl+Shift・Win+Shift+S | その時点の画面(操作前・操作後とも同じ画像を別ファイルで保存) |

「撮影の設定」タブで、操作の種類ごとに「記録する」「操作前を撮る」「操作後を撮る」を選べます。
キーは次のグループに分かれていて、グループごとにまとめて記録する / しないを選べます。

| グループ | キー | 既定 |
|---|---|---|
| A〜Z | 文字キー(Shift と一緒に押したものを含む) | 記録しない |
| 1〜0 | 数字キー(テンキーを含む) | 記録しない |
| F1〜F24 | ファンクションキー | 記録しない |
| 十字キー | ← ↑ → ↓ | 記録しない |
| 特殊キー | Enter・Tab・Esc・BackSpace・Delete・Insert・Home・End・PageUp・PageDown・Space など | 記録しない |
| Ctrl / Alt / Win との組み合わせ | Ctrl+S・Alt+F・Win+← など(どのキーでも) | 記録しない |

A〜Z・1〜0 を「記録する」にしても、テキストボックスなどの入力欄の中で押したものは文字入力として扱い、手順にはしません
(入力欄の外で、キー 1 つで操作するアプリ向け)。入力欄の中の十字キー・BackSpace・Delete・Space なども同じく文字の編集として扱います。
また「操作前は何 ms 前の画面にするか」「操作後は何 ms 後の画面にするか」も変えられます
(画面の切り替わりが遅いアプリでは、操作後の ms を大きくします)。

手順ごとに、次の情報も記録されます(Windows のステップ記録ツールと同じ項目)。

| 項目 | 内容 |
|---|---|
| 日時 | 操作した日時(ミリ秒まで) |
| 座標 | 画面上の X・Y と、ウィンドウ内の X・Y |
| クラス名 | 操作した部品のクラス名(UI Automation) |
| プログラム | 製品名・バージョン・会社名・コマンドライン・exe 名 |
| UI 要素 | 操作した部品から最上位のウィンドウまでの名前(名前が無ければクラス名)を順に並べたもの |

記録されないもの:

- ふつうの文字キー(入力した文字は、上の「テキストボックスへの入力」としてまとめて記録されます)
- 日本語入力の変換・確定の操作
- **パスワード欄に入力した文字**(「パスワードを入力します」とだけ書かれます)
- ウィンドウを別のディスプレイへ移すドラッグ
- **UAC の確認画面**(管理者権限でも記録できません)

出力する操作前の画像には、クリックした位置の丸(左クリック = 赤、右 = 青、中 = 緑)や、操作した部品を囲むオレンジの枠などの印が描かれます。
印の種類と丸の大きさは「出力の設定」タブで変えられます(3.3)。

## 3. 記録を確認して、md / HTML を出力する

「記録一覧・編集・出力」タブを開きます。

1. 左の一覧から記録を選びます(新しい順)。
2. 右側で手順を選ぶと、その手順の記録内容(日時・座標・クラス名・プログラム・UI 要素)と、
   操作前・操作後の画像が横に並んで表示されます。画像をダブルクリックすると大きく表示します。
   ドラッグした手順は、操作前の画像に、押した位置の丸から離した位置(移動先)への矢印が描かれます。
3. **手順の文章を直せます。** 「見出し」「本文」を書き換えて「この手順の文章を保存」を押します。
   直した手順には ✎ が付きます。「自動の文章に戻す」で元に戻せます。
   (直した内容は記録フォルダの `edits.json` に保存され、記録そのものは書き換えません)
   要らない手順は「この手順を削除」で記録から消せます。後ろの手順の番号は 1 つずつ繰り上がります(消した手順の画像はごみ箱へ移します)。
4. 「見出しの名前」「冒頭に載せる解説」を直せます。「名前・解説を記録に保存」を押すと記録に保存され、次からも使われます。
5. 文章の種類(テンプレート)と画像(PNG を参照 / base64 で埋込)を選び、「HTML で出力」か「Markdown で出力」を押します。
   出力したファイルはすぐに開きます。「保存フォルダを開く」で、出力先のフォルダを開けます。

同じ記録から、テンプレートや文章を変えて何度でも出力できます。記録し直す必要はありません。

不要になった記録は「この記録を削除(ごみ箱へ)」で消せます(ごみ箱から元に戻せます)。

出力する報告書は、**文章の種類(テンプレート。3.1)**・**画像に描く印(3.3)**・**画像の載せ方(3.4)** で決まります。
操作前・操作後の画像の並べ方はテンプレートごとに決まっています(3.2)。

### 3.1 文章の種類(テンプレート)

一覧には説明が先に出て、後ろの [ ] にテンプレートの名前が付いています。

| テンプレート | 内容 |
|---|---|
| user | ユーザー向けの手順書（操作前後画像）。手順ごとに、文章・画面名・操作前と操作後の画像 |
| psr | ステップ記録ツール形式（簡易UI操作履歴）。Windows のステップ記録ツールと同じ形式で、手順ごとに「『〇〇 (ボタン)』をクリック ― ウィンドウ『…』」の 1 行と、日時・座標・プログラム・UI 要素・クラス名を並べる |
| ai | AI向けの手順書（操作前後画像と詳細UI情報）。user の内容に加えて、ウィンドウ名・部品の名前と ID・ウィンドウ内の座標・プログラム・UI 要素などを載せる(AI が操作を再現するため) |
| text | テキスト手順書（操作情報のみ）。画像を載せず、手順ごとの文章・入力内容・画面名だけを並べる(メールやチャットにそのまま貼れる) |

### 3.2 画像の並べ方(テンプレートで決める)

user・ai・psr は、操作前と操作後を左右 2 列の表に並べます(text は画像を載せません)。
別の並べ方にしたいときは、テンプレートのエディタ(5 章)でテンプレートを複製し、画像を置く行を次のどれかに書き換えます。

| 書き方 | 並べ方 |
|---|---|
| `{{images.side}}` | 操作前と操作後を左右 2 列の表にする |
| `{{images.vertical}}` | 操作前の下に操作後を載せる。画像が大きく見える |
| `{{images.before}}` | 操作前の画像だけ。クリック位置の丸で「どこを操作するか」を示す手順書向け |
| `{{images.after}}` | 操作後の画像だけ |
| `{{images.sideMerged}}` / `{{images.verticalMerged}}` | 左右 / 縦に並べる。ただし操作前と操作後が同じ画面(画面が変わらなかった操作や Ctrl+Shift で撮った画面)なら「操作前・操作後(画面の変化なし)」として 1 枚にまとめる |

### 3.3 画像に描く印

操作前の画像には、操作した場所が分かる印を描きます。記録した画像には印を描かずに保存してあり、
**出力するときに**、記録した座標・部品の位置から合成します。「出力の設定」タブの「画像に描く印」で選べ、
何度でも描き方を変えて出力し直せます(記録一覧の画像にも、同じ印を描いて表示します)。

| 印 | 内容 | 既定 |
|---|---|---|
| マウスポインタ | クリックした位置に矢印のポインタ | 描かない |
| クリック位置の丸 | 左クリック = 赤 / 右 = 青 / 中 = 緑の丸(半径を px で指定) | 描く |
| ドラッグの矢印 | 押した位置から離した位置(移動先)への矢印 | 描く |
| 操作した部品の枠 | 操作したボタン・入力欄などを囲う橙の枠 | 描く |

v1.2 までに記録したものは、画像に丸などを描いて保存してあるので、印は重ねません。

### 3.4 画像の載せ方

| 載せ方 | 特徴 |
|---|---|
| PNG を参照 | ファイルが軽い。**md / HTML と一緒に記録フォルダ(img フォルダ)も渡す必要がある** |
| base64 で埋込 | md / HTML 1 ファイルで完結する。ファイルは大きくなる。md の埋め込み画像を表示できないビューア(GitHub など)もある |

### 3.5 画面を出さずに出力する

同じ出力を、コマンドからもできます(たくさんの記録をまとめて出力し直すときなど)。PowerShell 7 で:

```powershell
& "C:\Tools\操作記録ツール\OperationRecorder.exe" --export <記録フォルダ> --template user --format html | Write-Output
```

`--template user,psr`(文章の種類)・`--format html,md`(形式)・`--embed`(画像を埋め込む)・`--out <フォルダ>`(出力先)が使えます。
exe の場所は、zip を展開したフォルダ(1.1 の例では `C:\Tools\操作記録ツール`)に読み替えてください。

### 3.6 複数の記録から1本の手順書を完成させる（0.1.3）

中断や取り直しで分かれた記録を、元の記録を残したまま新しい記録へ合成できます。

1. 「記録一覧・編集・出力」で、Ctrl / Shift キーを使って合成する記録を複数選び、「選択した記録を合成…」を押します。1件から始め、合成画面の「別の記録を追加…」で追加することもできます。未保存の文章がある場合は、先に記録へ保存してください。
2. 最初は開始日時の順に記録を読み込み、操作の対象・種類・順序から重複候補をまとめます。初期案は後の記録を優先します。同じボタンでも目的や画面状態が異なる場合があるため、候補は必ず確認してください。クリック座標や入力文字の一致を保証する判定ではありません。
3. 中央の「完成する手順・順番」で手順を1つ選ぶと、右側で採用元・文章・操作前後の画像を確認できます。重複候補が複数ある場合は採用元を切り替えられます。「重複候補を比較」タブで画像と文章を比べ、画像はダブルクリックで拡大できます。
4. 不足する手順は、左側で元の記録を切り替え、必要な手順をCtrl / Shiftで選びます。中央で差し込み先を選び、「選択行の前へ」「選択行の後へ」または「末尾へ追加」を押します。不足分だけ追加記録したフォルダーも読み込んで差し込めます。
5. 中央で手順を複数選び、「先頭へ」「↑ 上へ」「↓ 下へ」「末尾へ」で並べ替えます。チェックを外すか「選択手順を除外」で不要部分を外し、「選択手順を採用」で戻せます。除外しても元の記録は消えません。
6. 右側の見出し・本文を書き換え、「この文章を反映」で合成作業に反映します。「説明だけの手順を追加」では画像のない補足説明も追加できます。「元に戻す」「やり直す」で作業の編集を戻せます。
7. 中断するときは「途中保存 (Ctrl+S)」を押します。採用元・順序・採否・文章を保存します。保存先は画面下に表示され、記録フォルダーの`.compositions/<作業ID>/draft.json`です。元の記録の画像と文章も同じ作業フォルダーに複製するため、**再開時に必要なのは作業フォルダー全体**です。draft.jsonだけを移動しないでください。
8. 再開するときは、記録一覧の「合成作業を再開…」から保存したdraft.jsonを選びます。元の記録が移動・削除されても、保存した作業フォルダー全体があれば再開できます。未保存のまま閉じる場合は保存・最後の保存状態を残して閉じる・キャンセルを選べます。
9. 「完成して新しい記録を作る」を押すと、採用した手順だけの新しいsession-*記録ができます。手順番号は振り直し、採用元の画像・保存済み文章・出典を引き継ぎます。元の記録と途中保存は残ります。完成した記録は通常の一覧から編集し、Markdown / HTMLを出力してください。

後から記録を追加しても、すでに選んだ採用元・採否・文章は保持します。新しく見つかった重複は候補として追加し、採用元の変更は利用者が選びます。「重複候補を推定して追加」のチェックを外すと、元記録だけを取り込み、必要な箇所を手動で差し込めます。

画像が欠けている・参照が不正・作業JSONが壊れている場合は理由を表示し、完成処理を中止します。元の記録は変更しません。元に存在しない操作画像を推測して作ることはありません。不足する操作は実際に追加記録して取り込んでください。

### 3.7 md / HTML の見方

HTML はブラウザ(Edge・Chrome など)で開くと、そのまま読めます。印刷や PDF への保存もブラウザからできます。

- `user-before`を選ぶと、すべての手順を操作前の画像だけで出力します。指定側の画像が無い手順に、反対側の画像を差し込むことはありません。
- 前後両画像を載せた手順書だけ、ページの上に「操作前と操作後 / 操作前だけ / 操作後だけ」が表示されます。切替は全部の手順に効きます。
  画面が変わらず 1 枚にまとめた画像は、どれを選んでも出ます。
- 画像をクリックすると、画面いっぱいに拡大します。右上の「閉じる（ESC）」、画像の外側のクリック、Escキーで元に戻ります。
- 印刷するときは切替と閉じるボタンは出ません。両画像の手順書では前後両方を印刷し、片側専用の手順書では選んだ側だけを印刷します。
- 表示切替・クリック拡大・閉じるボタンはJavaScript無効でも動きます。Escキーで閉じる機能にはJavaScriptが必要です。
  メールのプレビューなどCSSが効かない所では、テンプレートで出力した画像がそのまま並びます。
md は、Visual Studio Code・Typora・Obsidian など Markdown を表示できるアプリで開くと、画像付きで読めます。
Word にしたいときは、これらのアプリの出力機能や pandoc を使ってください。

### 3.8 記録から操作を再現する

記録は`--replay import`でconfigへ変換し、`--replay check`で不足を確認してから`run`または`watch`で再生できます。手動、日時、繰り返し、ホットキー、アプリ起動待ちに対応し、各手順でもウィンドウ・クラス・UI要素・画像が一致するまで監視します。

対象を特定できないときは理由を示して停止します。記録時の座標を無条件に送信することはなく、通常記録との同時実行もしません。詳細な使い方とconfig項目はアプリに同梱する`docs/replay.md`を参照してください。

毎回クラス名・タイトル・要素IDが変わる場合は、同じ操作を複数回記録して`New-OperationReplayWithCodex.ps1`から条件案を作成できます。Codex CLIへの比較用プロンプト、正規表現/条件式、対応付けと根拠を生成し、利用者が確認してから再生用configとして受け入れます。手順は`docs/replay-learning.md`を参照してください。

## 4. 保存場所

| もの | 場所 |
|---|---|
| 記録(画像・操作データ・md) | `ドキュメント\OperationRecords\session-日時_名前\`(「記録を保存するフォルダ」で変更可) |
| md | 記録フォルダの中(「md を保存するフォルダ」で変更可) |
| 設定 | `%APPDATA%\OperationRecorder\settings.json` |
| テンプレート | ツールと同じ場所の `templates` フォルダ(「設定」タブで変更可) |

記録フォルダの中身:

| ファイル | 内容 |
|---|---|
| `img\0001_before.png` など | 手順ごとの操作前・操作後の画像 |
| `events.jsonl` | 1 行 1 手順の操作データ |
| `session.json` | 記録の名前・解説・日時・対象などの情報 |
| `session-日時_テンプレート名.md` / `.html` | 出力した報告書 |
| `edits.json` | 記録一覧で直した手順の文章(直したときだけ作られる) |

画像を直接編集してから md を出力し直すこともできます(画像のファイル名は変えないでください)。

## 5. テンプレートを自分で作る

「記録一覧・編集・出力」タブの「テンプレートを編集…」で、テンプレートのエディタが開きます。

| 場所 | できること |
|---|---|
| 左 | テンプレートの一覧。名前を入れて「今のテンプレートをもとに追加」で、開いているテンプレートをコピーして追加します。「このテンプレートを削除」はごみ箱へ移します |
| 中 | テンプレートの中身を書き換えて「保存」。書き方に誤り(`{{#if}}` に `{{#endif}}` が無いなど)があると、理由を出して保存しません |
| 右 | 記録一覧で選んでいた記録に当てはめたプレビュー。「プレビューを更新」で、保存していない中身のまま確認できます |

テンプレートは「設定」タブの「テンプレートのフォルダ」にあるものを編集します。社内様式などを分けて置きたいときは、
別のフォルダ(例: `D:\社内様式`)を指定して「反映」を押してから、エディタで追加してください。

書き方(各テンプレートの冒頭のコメントに、使える変数の一覧があります):

| 書き方 | 意味 |
|---|---|
| `{{変数}}` | 値を差し込む(例: `{{caption}}` `{{headline}}` `{{before.image}}`) |
| `{{#if 変数}} … {{#else}} … {{#endif}}` | 値があるときだけ出す |
| `{{#unless 変数}} … {{#endunless}}` | 値がないときだけ出す |
| `{{#each steps}} … {{#endeach}}` | 手順ごとに繰り返す |
| `{{!-- … --}}` | コメント(出力しない) |

テンプレートの 3 行目(`操作報告書テンプレート(説明)` の行)が、一覧に表示される説明になります。

## 6. 困ったときは

| 症状 | 対処 |
|---|---|
| 「ホットキーを登録できません」と出る | 他のアプリが Ctrl+Shift+F9 を使っています。そのアプリを終了するか、「記録を開始」ボタンで始めてください |
| 「すでに起動しています」と出る | ツールはタスクトレイにあります。トレイのアイコンをダブルクリックしてください |
| 記録が始まらない・何も撮られない | 対象を「最初にクリックしたもの」にしている場合は、まず対象のウィンドウを 1 回クリックしてください |
| 管理者として実行したアプリの操作が記録されない | 「設定」タブの「管理者として再起動」でツールを管理者権限で動かしてください |
| 画像に斜線の部分がある | 対象の外(重なった他のウィンドウなど)を塗りつぶした部分です。対象を前面に出して記録してください |
| 会社のセキュリティソフトに止められる | キーボードの操作を検知する仕組みを使うため、警告されることがあります。管理者に相談してください |
| md の画像が表示されない | 「PNG を参照する」で出力した md は、記録フォルダの img フォルダと一緒に置く必要があります |

### 注意

- 記録には、撮影した画面と、入力した文字(パスワード欄を除く)が保存されます。個人情報や社外秘の情報が
  写らないよう、記録する前に関係ない画面を閉じてください。記録や md を人に渡す前に、画像と文章を確認してください。
- 手順書の文章は、画面の部品の名前から自動で作っています。配る前に読み直して、必要なら直してください。

## 付録: コマンドで使う(PowerShell 7)

ツールの画面を使わず、コマンドでも記録・出力できます(Claude Code の operation-recorder スキルとして入っている場合)。
スクリプトは `%USERPROFILE%\.claude\skills\operation-recorder\scripts\` にあります。

| 目的 | コマンド |
|---|---|
| 質問に答えながら記録する | `pwsh -File Start-OperationRecording.ps1` |
| 設定を指定して記録する | `pwsh -File Start-OperationRecording.ps1 -Caption "受注登録" -Mode App -Pick -Open` |
| ディスプレイの番号を調べる | `pwsh -File Start-OperationRecording.ps1 -ListMonitors` |
| 過去の記録から md を作り直す(対話式) | `pwsh -File Reissue-OperationReport.ps1` |
| 記録フォルダを指定して md を作る | `pwsh -File New-OperationReport.ps1 -SessionDir <記録フォルダ> -Template user,ai` |

パラメータの一覧は `Get-Help <スクリプトのパス> -Full` で表示できます。

# OperationRecorder 0.1.5公開記録

依頼日：2026-11-01。「OperationRecorder 0.1.5をリリースして、本体から更新できるようにする」という明示依頼に基づく。インストール済みアプリの更新・終了やOS予約の変更は含めない。

- [ ] R1：採用コミットから自己完結パッケージとsetupを生成し、配布入力の秘密検査・非実行展開・全ファイル照合を行う。
- [ ] R2：独立Gitのmainと新規タグv0.1.5へ公開し、setup・SHA256SUMS・製品別台帳を匿名で再取得する。
- [ ] R3：本体公開configとrelease-indexを更新し、本体と同じ公開照合・ダウンロード経路を検証する。

製品コードの試験結果は[実装報告](v0.1.5-imp.md)のCore412件＋Desktop52件（計464件成功）を採用する。リリースで製品コードを変更しない限り、同じ実入力試験を形式的に繰り返さない。配布された自己完結EXEのCLIと配布内容は別に確認する。

初回の発行は公式ランタイム検査で停止した。子の固定.NET 10.0.13に対し、Microsoft公式メタデータの最新は10.0.14（2026-10-25公開）だったため、Core/Desktop両方の自己完結ランタイムを10.0.14へ更新した。中止した発行物は公開せず、更新コミットから再生成する。

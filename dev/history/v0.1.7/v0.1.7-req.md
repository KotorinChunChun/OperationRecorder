# OperationRecorder 0.1.7 要求

- [x] R1：外部自動操作向けの非表示汎用API（StartSession/BeginStep/EndStep/RecordFailure/Flush/StopSession）を追加し、PS7利用例と公開契約を記録する。
- [x] R2：同一ユーザー限定、対象PID・開始時刻・EXE・Windowsセッションの再検証、要求ID・工程ID・期限、保存完了応答と重複/未完了/成否不明の区別を実装する。
- [x] R3：before/afterを別々に確定し、途中クラッシュでもbeforeを残し、入力フックに依存せずUIA/ネイティブ操作前後を明示的に記録できる。
- [x] R4：対象部品と周辺UI情報を上限付きで取得し、スキーマ版・実行/工程ID・時刻・動画時刻・実装版/ハッシュを残し、対象外アプリを撮影しない。
- [x] R5：認証領域はName/Value/Textを読む前に安全性を判定し、未知は取得せず、PNG/MP4の保存/エンコード前に秘密領域をマスクして中間画像・ログ・例外・IPCにも秘密を残さない。
- [x] R6：UIA停止/撮影不能/保存不能/呼出し元死亡を期限付きで扱い、必要ならワーカーを分離し、録画障害が呼出し側の緊急終了を妨げない。
- [x] R7：改修前の既存試験を基準に、操作前失敗時の操作禁止、相関/重複/欠落/クラッシュ、障害注入、誤対象拒否、ダミー秘密の非残留、既存記録/出力/設定保持を検証する。
- [x] R8：既存の人向け記録・リプレイを維持し、フェーズ別に検証・差分点検・コミットし、保証範囲と実アプリ未受入を報告する。
- [x] R9：実際の対象アプリ、実資格情報、業務データ、他リポジトリ、通知、常駐設定、他PC導入、追加機能のpush/リリースを今回の対象にしない。
- [x] R10：対象アプリの終了/強制終了/再列挙は呼出し側の責任とし、Recorderへ対象アプリ専用の終了処理や年月操作を組み込まない。
